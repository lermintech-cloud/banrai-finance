# หน้าเว็บ

`public/index.html` คือหน้าเว็บทั้งระบบในไฟล์เดียว ไม่มีขั้นตอน build Worker ส่งไฟล์นี้ให้เบราว์เซอร์พร้อม security headers

- เปิดผ่าน Worker: ตรวจ `/api/auth/me` → ถ้ามี API จะเข้าโหมดฐานข้อมูลกลาง (ต้องเข้าสู่ระบบ ไม่เก็บข้อมูลการเงินใน localStorage)
- เปิดไฟล์จากเครื่องโดยตรง: โหมดสาธิต ข้อมูลตัวอย่างเก็บใน localStorage ของเบราว์เซอร์ สลับบทบาทได้เพื่อฝึกใช้
- สิทธิ์ที่เห็นบนหน้าจอเป็นเพียงการซ่อน/แสดงปุ่ม การบังคับจริงอยู่ที่ Worker และฐานข้อมูล

ข้อจำกัดที่รู้: โค้ดและสไตล์อยู่ในไฟล์เดียว จึงต้องอนุญาต `'unsafe-inline'` ใน Content-Security-Policy
การแยกเป็นไฟล์ `.js`/`.css` หรือย้ายไป React + Vite ตามพิมพ์เขียวข้อ 11 จะทำให้เข้ม CSP ได้ขึ้น (งานระยะถัดไป)
ค่าที่เก็บในเบราว์เซอร์ต่อเครื่อง: การแสดงผล (สี/ความสว่าง) ระยะขอบกระดาษ และตัวเลือกพิมพ์ทั้งเล่ม
