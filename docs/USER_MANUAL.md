# คู่มือผู้ใช้

เปิดเว็บของระบบ (ที่อยู่ที่ผู้ดูแลแจ้ง) ด้วย Chrome, Edge หรือ Safari รุ่นปัจจุบัน

## เข้าสู่ระบบ
- ใช้ชื่อผู้ใช้และรหัสผ่านที่ผู้ดูแลระบบออกให้ ครั้งแรกระบบจะให้ตั้งรหัสผ่านใหม่ของตนเอง (อย่างน้อย 10 ตัวอักษร)
- ใส่รหัสผิด 5 ครั้ง บัญชีจะถูกล็อก 15 นาที
- แต่ละคนใช้บัญชีของตนเอง ห้ามใช้ร่วมกัน เพราะระบบแยกหน้าที่และบันทึกประวัติตามบัญชี
- มุมขวาบน: ชื่อผู้ใช้ ปุ่ม **โหลดใหม่** (ดึงข้อมูลล่าสุดที่คนอื่นเพิ่งทำ) **รหัสผ่าน** และ **ออกจากระบบ**
- ข้อมูลทุกอย่างอยู่ในฐานข้อมูลกลาง ทุกคนเห็นชุดเดียวกัน ระบบโหลดข้อมูลใหม่เองเมื่อเปลี่ยนเมนูหรือกลับมาที่แท็บ

| บทบาท | ทำได้ |
| --- | --- |
| เจ้าหน้าที่การเงิน | บันทึกรับ สร้างคำขอจ่าย บันทึกจ่าย ตั้งค่าเอกสาร/ผู้ลงนาม เพิ่มโครงการ |
| เจ้าหน้าที่บัญชี | ตรวจรายการ ยืนยันรับเงิน กลับรายการ กระทบยอดธนาคาร |
| ผู้อำนวยการ | อนุมัติ ตั้งค่าระบบ แหล่งเงิน ปีงบประมาณ เอกสาร/ผู้ลงนาม เพิ่มโครงการ |
| ผู้ตรวจสอบ | ดูอย่างเดียว รวมถึงบันทึกตรวจสอบ |
| ผู้ดูแลระบบ | จัดการผู้ใช้ ตั้งค่าระบบ ดูบันทึกตรวจสอบ (ไม่ทำรายการเงิน) |
| ผู้เบิก | สร้างคำขอและติดตามสถานะ |

โหมดสาธิต: ถ้าเปิดไฟล์ `index.html` จากเครื่องโดยตรง จะไม่มีการเข้าสู่ระบบ ข้อมูลตัวอย่างเก็บในเบราว์เซอร์ และสลับบทบาทได้ที่มุมขวาบน ใช้ฝึกเท่านั้น

## หน้าแรก
- แบนเนอร์: ยอดคงเหลือรวม และปุ่มลัดบันทึกรับ/สร้างคำขอเบิก
- **เมนู** 4 หมวด หมวดละ 3 รายการ: งานประจำวัน, งบและบัญชี, เอกสารและรายงาน, ระบบและการตรวจสอบ ตัวเลขสีทองคือจำนวนงานที่รอดำเนินการ
- **ตัวเลขสำคัญ** 4 ช่อง คำนวณจากทะเบียนคุมทุกครั้ง
- **เปรียบเทียบ**: กราฟรับ–จ่ายรายเดือน, ตารางเดือนนี้เทียบเดือนก่อน, ตารางเปรียบเทียบแหล่งเงิน, สัดส่วนเงินคงเหลือ, ยอดคงเหลือรวมรายเดือน, งบโครงการเทียบจ่ายจริง ชี้ที่กราฟเพื่อดูตัวเลข
- บนมือถือ เมนูหลักอยู่แถบล่าง ปุ่ม "เมนู" เปิดเมนูทั้งหมด

## คำอธิบายและการยืนยัน
- ทุกส่วนมีคำอธิบายสั้นใต้หัวข้อ และปุ่ม **?** สำหรับคำที่อาจไม่คุ้น (กดหรือชี้เพื่ออ่าน)
- **ก่อนบันทึก** ทุกฟอร์มจะแสดงหน้าสรุปให้ตรวจ ต้องกด "ยืนยันบันทึก" อีกครั้งจึงจะบันทึก กด "กลับไปแก้ไข" ได้
- **ทุกขั้นตอนงาน** (ส่งตรวจ ตรวจ อนุมัติ จ่าย ยืนยันรับ) มีกล่องยืนยันพร้อมอธิบายผลที่จะเกิด
- **หลังบันทึก** มีแถบแจ้งด้านบนพร้อมเวลา และป้าย "บันทึกล่าสุด ..." ที่มุมขวาบน
- หน้าตั้งค่า: ถ้าแก้แล้วยังไม่กดบันทึก ป้ายจะเปลี่ยนเป็น "มีการแก้ไขที่ยังไม่ได้บันทึก" และระบบจะเตือนเมื่อออกจากหน้า

## ขั้นตอนงานหลัก
**รับเงิน**: เมนู "รับเงิน" → บันทึกรับเงิน → ตรวจสรุป → ยืนยัน → เจ้าหน้าที่บัญชี "ยืนยันรับเงิน" (ได้เลขใบเสร็จ ยอดคงเหลือเพิ่ม)
**จ่ายเงิน**: เมนู "เบิกจ่าย" → สร้างคำขอ → ส่งตรวจ → (บัญชี) ตรวจ → (ผอ.) อนุมัติ → (การเงิน) บันทึกจ่าย (ได้เลขใบสำคัญ ยอดคงเหลือลด)
- ขั้น "อนุมัติ" แค่กันวงเงิน ยังไม่ลดยอดคงเหลือ
- ผู้สร้างรายการตรวจ/อนุมัติรายการของตนเองไม่ได้
- ปฏิเสธต้องใส่เหตุผล
- รายการที่ลงบัญชีแล้วแก้หรือลบไม่ได้ ต้อง "กลับรายการ" พร้อมเหตุผล

## เอกสาร (ออกทีละฉบับ)
เมนู **เอกสาร** → เลือกแบบ → กรอกเฉพาะข้อมูลของฉบับนั้น → ดูตัวอย่างด้านขวา → พิมพ์

แบบที่มี 12 แบบ (ทุกแบบเป็นต้นแบบ รอตรวจกับระเบียบ)
- หลักฐานรับ–จ่าย: ใบเสร็จรับเงิน, ใบสำคัญจ่าย, ใบรับรองแทนใบเสร็จรับเงิน
- หนังสือราชการ: บันทึกข้อความขออนุมัติเบิกจ่าย, บันทึกข้อความรายงานการเงิน
- รายงาน: เงินคงเหลือประจำวัน, สรุปรับ–จ่าย–คงเหลือ, รับ–จ่ายประจำเดือน, ทะเบียนคุมเงิน, การใช้จ่ายงบโครงการ, งบกระทบยอดเงินฝากธนาคาร
- ประกอบเล่ม: ปกรายงานการเงิน

รายงานที่ยาวจะแบ่งหน้าเองและระบุ "แผ่นที่ 1/3" ลายเซ็นอยู่หน้าสุดท้าย

## พิมพ์ทั้งเล่ม
เมนู **พิมพ์ทั้งเล่ม**
1. เลือกเดือน
2. ติ๊กเอกสารที่ต้องการ (11 รายการ) ใช้ลูกศรเลื่อนลำดับ หรือพิมพ์ลำดับในช่อง เช่น `1-2+3` = ลำดับ 1 ถึง 2 และ 3 (ใช้ `,` แทน `+` ได้ ใช้เลขไทยได้)
3. เลือกว่าจะใส่เลขหน้าหรือไม่ (ไม่นับปก) สารบัญสร้างให้อัตโนมัติตามที่เลือก
4. ดูตัวอย่างทุกหน้า แล้วกด "พิมพ์ / บันทึก PDF"

ตัวเลือกในหน้านี้ระบบจำไว้ในเครื่องนั้น

การพิมพ์: เลือกกระดาษ A4 ขอบกระดาษถูกกำหนดโดยระบบแล้ว ไม่ต้องตั้ง Margins ซ้ำ

**ตั้งค่าหน้ากระดาษ**: ปุ่มเดียว เปิดหน้าต่างปรับขอบ ขนาดอักษร ระยะบรรทัด ค่ามาตรฐานในต้นแบบยังไม่ได้รับการรับรอง (ดู `REGULATIONS_REGISTER.md`) เก็บต่อเครื่อง

## ตั้งค่า
- **ปีงบประมาณ** (ผอ./ผู้ดูแล): เปิดปีถัดไป และปิดปีปัจจุบัน ปิดแล้วบันทึกในปีนั้นไม่ได้อีกและเปิดกลับจากหน้าจอไม่ได้ ต้องไม่มีรายการค้าง ควรพิมพ์ทั้งเล่มและสำรองข้อมูลก่อน
- **เอกสารและผู้ลงนาม** (การเงิน/ผอ./ผู้ดูแล): ชื่อโรงเรียน ที่อยู่ ส่วนราชการ "เรียน" ตั้งต้น ชื่อ-ตำแหน่งผู้ลงนาม ผู้ลงนามบันทึกข้อความ ตราครุฑ (PNG/JPG ไม่เกิน 1 MB) ตั้งครั้งเดียวใช้ทุกฉบับ ต้องกดบันทึก
- **แหล่งเงิน** (ผอ./ผู้ดูแล): เพิ่มพร้อมยอดยกมา, ปุ่ม **แก้ไข** (ชื่อ และยอดยกมาถ้ายังไม่มีรายการ — ผู้ดูแลระบบแก้ยอดยกมาได้เสมอ), ปุ่ม **ลบ** เฉพาะแหล่งเงินที่ยังไม่มีรายการ (เช่น แหล่งที่สร้างไว้ทดลอง) ทุกการแก้/ลบบันทึกในประวัติ
- **ผู้ดูแลระบบ** ทำได้ทุกบทบาท (ต้องวางไฟล์ `0009` ก่อน) แต่ยังอนุมัติหรือยืนยันรายการที่ตนเองสร้างไม่ได้
- การแสดงผลและหน้ากระดาษ: เก็บต่อเครื่อง

## ผู้ใช้งาน (ผู้ดูแลระบบ)
เพิ่มผู้ใช้ (กำหนดบทบาทและรหัสผ่านชั่วคราว แล้วแจ้งเจ้าตัวโดยตรง) ปิด/เปิดบัญชี ตั้งรหัสผ่านใหม่ บัญชีที่ปิดแล้วเข้าไม่ได้ทันทีแต่ประวัติยังอยู่
ยังเปลี่ยนบทบาทของบัญชีเดิมจากหน้าจอไม่ได้ ให้ปิดบัญชีเดิมแล้วสร้างใหม่

## ปัญหาที่พบบ่อย
| อาการ | แก้ |
| --- | --- |
| ไม่เห็นรายการที่เพื่อนเพิ่งบันทึก | กด "โหลดใหม่" ที่มุมขวาบน |
| ขึ้นว่า "มีผู้อื่นทำรายการนี้ไปก่อนแล้ว" | ระบบโหลดข้อมูลล่าสุดให้แล้ว ตรวจสถานะใหม่อีกครั้ง |
| ถูกพากลับหน้าเข้าสู่ระบบ | หมดเวลา 12 ชั่วโมง หรือบัญชีถูกปิด/เปลี่ยนรหัส เข้าสู่ระบบใหม่ |
| พิมพ์แล้วมีหัว-ท้ายกระดาษของเบราว์เซอร์ | ในกล่องพิมพ์ปิด "Headers and footers" |
| ตราครุฑไม่ขึ้น | อัปโหลดรูป PNG หรือ JPG (ไม่เกิน 1 MB) ในตั้งค่า > เอกสารและผู้ลงนาม; ชุดนี้ไม่ได้แนบรูปครุฑ ต้องใช้ฉบับที่หน่วยงานอนุญาต |
| ตัวอักษรไม่ใช่ TH Sarabun New | เอกสารเรียก TH Sarabun New / TH SarabunPSK ในเครื่องก่อน ถ้าไม่มีจะใช้ Sarabun (โหลดจาก Google Fonts ต้องออนไลน์) แล้ว Tahoma — ติดตั้ง TH Sarabun New ในเครื่องเพื่อให้ตรงแบบ |
