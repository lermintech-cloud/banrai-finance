## ข้อจำกัดสำคัญจากพิมพ์เขียว
- เอกสารเป็นการออกแบบทางเทคนิค ไม่ใช่คำรับรองว่าแบบบัญชีหรือแบบฟอร์มใดถูกต้องตามระเบียบราชการ
- ห้ามใส่รหัสผ่านจริง API Token Cloudflare Account ID หรือ Secret ในเอกสาร Git หรือโค้ด
- ห้ามระบุว่าเอกสารใดเป็นแบบราชการที่ถูกต้อง จนกว่าจะเทียบกับต้นฉบับปัจจุบันและผู้รับผิดชอบรับรอง
