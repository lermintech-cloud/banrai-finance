# ทะเบียนระเบียบและแบบฟอร์ม (ต้องกรอกและรับรองก่อนใช้จริง)

พิมพ์เขียวกำหนดว่า **ห้ามระบุว่าเอกสารหรือกติกาใดถูกต้องตามระเบียบ จนกว่าจะตรวจกับต้นฉบับปัจจุบัน**
ไฟล์นี้เป็นแม่แบบ: ทุกแถวด้านล่างเป็น **"ยังไม่ตรวจสอบ"** ผู้ผลิตระบบไม่ได้รับรองความถูกต้องของรายการใด

วิธีใช้: ผู้รับผิดชอบ (เจ้าหน้าที่การเงิน/ผู้อำนวยการ หรือตามที่โรงเรียนมอบหมาย) เทียบกับต้นฉบับล่าสุด
จากหน่วยงานที่ออกระเบียบ แล้วกรอก "แหล่งอ้างอิง/เวอร์ชัน" "ผู้ตรวจ" "วันที่ตรวจ" และเปลี่ยนสถานะ

## 2. ข้อมูลที่ต้องขอจากโรงเรียน (พิมพ์เขียวข้อ 16)

รายชื่อและตำแหน่งผู้ลงนามจริง, ตราครุฑฉบับที่หน่วยงานอนุญาตให้ใช้, ประเภทเงินและแหล่งเงินที่ใช้จริงพร้อมเงื่อนไข,
ยอดยกมาและวันที่ยกมา, บัญชีธนาคาร, รูปแบบเลขเอกสารที่ใช้จริง, ผู้มีอำนาจอนุมัติและวงเงิน,
RPO/RTO ที่ยอมรับ (ข้อมูลสูญหายได้กี่ชั่วโมง กู้คืนภายในกี่ชั่วโมง)

## 3. กติกา
- ห้ามเปลี่ยนสถานะเป็น "ตรวจแล้ว" โดยผู้พัฒนาเอง ต้องเป็นผู้รับผิดชอบของโรงเรียน
- เมื่อระเบียบเปลี่ยน ให้เพิ่มแถวใหม่/อัปเดตเวอร์ชัน แล้วค่อยแก้โค้ด/แม่แบบเอกสาร และบันทึกวันที่
- เอกสารที่พิมพ์ออกจากต้นแบบในระหว่างที่ยังเป็น "ยังไม่ตรวจสอบ" ใช้เป็นตัวอย่างเท่านั้น
